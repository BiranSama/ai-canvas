# 生图提示词写法

generate 的 brief 和 edit_image 的 instruction 会交给生图模型。按当前生图服务的家族来写，效果差别很大。

## 通用写法
- 写完整的画面：主体是什么、在哪里、什么姿态，环境、光线、氛围、风格、镜头。
- 先主体，后环境，最后风格；一句话说一件事。
- 要保留的东西明确说出来：「保持瓶身文字不变」「人物面部不变」。
- 不要在 brief 里写画面上的排版文字，文字由画布上的文字对象负责。

## 为主体占位单独生成（会被抠出来）
- 只画这一个主体：完整入画、不被裁切，四周留一点空白。
- 背景写成干净的纯色，和主体颜色拉开对比，不要场景、地面和其他物体，方便抠图。
- 光线方向和色温跟画布上已有的光一致，例如「左上方暖色柔光」，放进画面才不突兀。

## OpenAI GPT Image
- 喜欢长而自然的描述，像给摄影师的拍摄说明。
- 必须出现的文字用引号写出，写清位置和字体风格。
- 可以描述构图比例和留白，例如「上方三分之一留空，用于放标题」。

## 火山方舟 Seedream
- 中文描述效果好，简洁有力；关键词之间用逗号。
- 有参考图时用「图1」「图2」指代：「参考图1的构图，图2的配色」。
- 写清风格和质感词：「商业摄影，柔和侧光，磨砂质感，浅景深」。

## xAI Grok 与 Google Gemini
- 叙述式描述，像讲一个画面；比例通过参数决定，不用写在文字里。
- 适合描述场景氛围和故事感。
- Grok 可以参考 1–3 张图（例如画布截图和已有成图），用「第一张图」「第二张图」指代；它没有蒙版，局部修改要换用支持蒙版的服务。

## 本地 SDXL
- 用英文标签式写法，逗号分隔，重要的词加权重：(perfume bottle:1.3), soft morning light, frosted glass。
- 一定要写反向提示词（低质量、变形、多余文字）。
- 不要写中文长句。

## 本地 Flux
- 英文自然语言描述效果最好。
- 反向提示词基本无效，要避免的东西直接在正向描述里说「干净背景，无文字」。

## 局部修改（edit_image）
- 只描述修改区里要变成什么，不要重述整张图：「把杯子换成白色陶瓷杯，保持光线方向」。
- 先用 add_mask 标出修改区；区域略大于要改的物体，边缘留羽化。
