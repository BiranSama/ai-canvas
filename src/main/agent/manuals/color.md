# 配色

## 基本方法
- 先定一个主色（占 60%）、一个辅色（30%）、一个点缀色（10%）。
- 背景通常用低饱和、浅或深的颜色，让主体和文字跳出来。
- 文字与背景的明度要拉开：浅底用 #1F2328 一类深色字，深底用 #F4F4F2 一类浅色字。

## 按情绪选色
- 清晨、清新：雾蓝 #A9BCCB、米白 #F1EFEA、淡金 #D8C39A。
- 温暖、生活方式：奶咖 #C8A78A、焦糖 #A8683C、暖白 #FAF6F0。
- 高端、克制：炭黑 #202329、暖灰 #8C8579、香槟 #CDB98F。
- 活力、促销：番茄红 #E2513A、明黄 #F2C230、深蓝 #1E3A5F。
- 自然、植物：橄榄绿 #6B7B4C、苔绿 #A3B18A、陶土 #B5654A。
- 科技、未来：深海蓝 #0E1A2B、电光蓝 #3D8BFF、冷白 #EAF2FA。

## 和主体协调
- 从主体本身取色做背景或文字色，画面最统一（如香水瓶的淡金色用在标题）。
- 互补色做点缀能强调卖点，但面积要小。
- 照片类主体背景避免高饱和色，以免抢主体。

## 光的颜色
- add_light 的颜色决定整体气氛：暖光 #FFD2A1，冷光 #A7C9F4，夕阳 #FFB37A，月光 #C9D6F2。
- 光色与背景同一色温，画面更统一；冷暖对比用于戏剧感。

## 检查清单
- 文字和背景的对比够吗？（浅底深字、深底浅字）
- 画面颜色是否超过三种主要颜色？
- 主体是不是画面里颜色最突出的部分？
