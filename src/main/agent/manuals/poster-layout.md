# 海报版式

## 先定结构，再放元素
1. 定比例：用户说了就用；没说时竖版海报默认 4:5，活动海报 3:4，户外长图 9:16。
2. 定焦点：一张海报只有一个主角——主体图像或大标题，二选一。
3. 定阅读顺序：主角 → 标题 → 副标题/卖点 → 说明信息（时间、地点、品牌）。
4. 最后补装饰：色块、分隔线、标签，只在能强化顺序时才加。

## 常用骨架（位置是画布百分比）
- **上字下图**：标题 [10, 7, 80, 14]，主体 [15, 30, 70, 58]，说明 [10, 90, 80, 5]。最稳，适合新品、活动。
- **下三分之一**：主体占满上部，文字组压在 y≈66–92 的带里。适合人物、风景。
- **侧边留白**：主体偏一侧（x 0–60），另一侧 35% 留白放竖排或左对齐标题。编辑感强。
- **中心对称**：主体居中，标题在上、信息在下，左右对称。庄重，适合节日、典礼。
- **对角动势**：主体放左下或右上，标题放对角，色带沿对角线。适合运动、促销。

## 层级与尺寸
- 标题字号约为画布宽度的 6–9%；副标题为标题的 45–60%；说明为 2–2.5%。
- 同一画面最多三级字号；拉开差距比微调更有效。
- 用字重和颜色区分层级，不要给每行都加粗。

## 留白与边距
- 安全边距：重要文字离四边至少 5%，印刷品 7% 以上更稳。
- 留白要成块：一大块干净留白胜过许多小缝隙。
- 标题与主体之间留出至少一行标题高度的距离；不能挤时缩小主体，不缩标题。

## 常见问题与改法
- **文字压住主体**：先把文字移到留白区（arrange lower-third 或 move），实在没有空间再缩小主体。
- **画面太满**：删掉最弱的装饰，而不是整体缩小。
- **层级不清**：放大标题或缩小其他文字，拉开到至少 2 倍差距。
- **重心不稳**：主体偏下更稳，偏上显得轻；空的那侧放文字平衡。

## 动手顺序建议
set_canvas → add_subject（先放主体，确定重心）→ add_text 标题 → 其他文字 → look 看一眼 → 用 arrange/update 微调 → look 复查。
