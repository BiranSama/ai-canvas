# 横幅

## 画幅
- 网页首屏、视频封面：16:9。
- 网站通栏、活动 Banner：3:1 或 4:1。
- 公众号头图：约 2.35:1。

## 横向阅读
- 视线从左到右：左侧放标题与行动信息，右侧放主体图像；或反过来，但文字一侧要有足够留白。
- 通栏横幅高度小，文字最多两行：标题 + 一句副标题。
- 行动按钮（「立即报名」）用色块 + 短字，放在标题下方或右侧末端。

## 版式
- **左文右图**：文字组占左侧 40–45%（x 6–46），主体占右侧。最常用。
- **中心标题**：标题居中，两侧用对称装饰或主体剪影，适合节日、发布会。
- **全幅背景 + 文字条**：背景是场景图，文字放在半透明色块上保证可读。

## 尺寸与边距
- 标题字号约为画布高度的 12–18%。
- 上下边距至少为高度的 10%，左右至少为宽度的 5%。
- 不同网站会再裁切两侧，最重要的内容放在中间 80% 宽度内。

## 检查清单
- 缩小到网页实际显示宽度时，标题仍然清楚吗？
- 文字和主体之间有足够的呼吸空间吗？
